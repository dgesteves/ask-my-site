The index that the Ask box answers from can also be served to agents, such as Claude Code, Cursor, VS Code, ChatGPT and Claude, as an MCP server. `createMcpHandler` from `ask-my-site/server` serves it with three read-only tools: `search`, `fetch` and `list_pages`. The agent brings its own model: the endpoint never calls a language model, and with no embedding model, it calls no model at all.

This site serves its own docs this way, at `https://ask-my-site-demo.vercel.app/api/mcp`. To try it in Claude Code:

```sh
claude mcp add --transport http ask-my-site https://ask-my-site-demo.vercel.app/api/mcp
```

Or add it to [Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=ask-my-site&config=eyJ1cmwiOiJodHRwczovL2Fzay1teS1zaXRlLWRlbW8udmVyY2VsLmFwcC9hcGkvbWNwIn0%3D), [VS Code](vscode:mcp/install?%7B%22name%22%3A%22ask-my-site%22%2C%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fask-my-site-demo.vercel.app%2Fapi%2Fmcp%22%7D) or [Claude](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=ask-my-site&connectorUrl=https%3A%2F%2Fask-my-site-demo.vercel.app%2Fapi%2Fmcp), or in ChatGPT, add a custom MCP server with that URL at chatgpt.com/plugins.

## Mount the endpoint

It is a Web-standard `(Request) => Promise<Response>`, like the ask endpoint, and it mounts the same way. In a Next.js app, `app/api/mcp/route.ts`:

```ts
// app/api/mcp/route.ts
import { createMcpHandler } from 'ask-my-site/server';
import index from '../../../ask-index.json';

const handler = createMcpHandler({ index, siteName: 'the Acme docs' });

export const POST = handler;
export const GET = handler;
export const DELETE = handler;
export const OPTIONS = handler;
```

Pass the same imported `index` to `createAskHandler` and `createMcpHandler`, and it is loaded into memory once for both. MCP clients send JSON-RPC with POST. The handler answers GET and DELETE with a 405, as a server without sessions does, and OPTIONS for browser clients.

For a static site, `npx ask-my-site init` writes it next to the ask endpoint: `api/mcp.ts` on Vercel, `netlify/functions/mcp.mts` on Netlify, `functions/api/mcp.ts` on Cloudflare Pages, or `/api/mcp` in the Worker it writes for a Cloudflare Worker or a GitHub Pages site, each rate-limited on the host's client IP header. On an Astro site with an SSR adapter, the integration serves `/api/mcp` itself. See [Deploying](/docs/deployment#write-the-endpoint-with-init).

## The tools

| Tool         | Input                                          | Returns                                                                                                                                                                                        |
| ------------ | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`     | `query`: keywords or a short question          | Up to 8 sections, best first, each with an `id`, the page `title`, the section's `heading` path, its absolute `url` with the anchor, and `text`, a snippet of the part that matches the query. |
| `fetch`      | `id`: an id from `search`, or a page URL       | The page as Markdown, or with an `#anchor`, that section. A page over 60,000 characters is cut, and the sections to fetch for the rest are listed.                                             |
| `list_pages` | `prefix` (optional): a path, as `/docs/guides` | Every page's `id`, `title` and `url`, or those under the prefix, up to 500.                                                                                                                    |

Results come back as structured content, and as the same JSON in a text block for clients that read only text. That is the shape ChatGPT's connectors and deep research expect from `search` and `fetch`. `fetch` also takes a URL as an agent might write it: absolute, with a trailing slash, or ending in `.md`. A page or tool that does not exist is an error the agent reads, with what to try instead.

## Keyword-only or hybrid search

Without an `embeddingModel`, `search` matches on keywords (BM25), and agent traffic costs you no model call of any kind. Agents write good search queries, so this works well. On docusaurus.io's own docs (92 pages, 1,070 chunks), searched as an agent searches ("autogenerated sidebar from folder", "configureWebpack"), the right page is in the top three for 22 of 22 queries, and first for 19. Asked as a person asks ("How do I add a tip or warning callout box?"), it is in the top three for 20 of 22. Those counts are checked in CI on every change.

With `embeddingModel`, each search also embeds its query, one embedding call at your provider's price, and merges both rankings as the ask endpoint does. That helps queries that share no words with the page. It must be the model the index was built with. If the provider fails, that search falls back to keywords.

```ts
const handler = createMcpHandler({
  index,
  embeddingModel: openai.embedding('text-embedding-3-small'),
});
```

## Limits

- **Rate limit.** 60 tool calls a minute per client IP by default, per server instance, keyed as the ask endpoint's are (see [which client IP header to trust](/docs/security#which-client-ip-header-to-trust)). Discovery and listing the tools are not counted. Hosted clients, ChatGPT and claude.ai, call from their own servers, so their users share a few IPs; raise the limit if many people use your docs from them.
- **Budget.** `budget: { requestsPerDay }` caps tool calls a day for the whole endpoint, apart from the ask endpoint's budget. There is no token budget, as nothing generates tokens.
- **Size.** Bodies over 64 KiB get a 413 while they are read, and queries over 500 characters an error.

## Protocol versions

The endpoint speaks MCP 2026-07-28, where every request names its version and there is no session, and, for clients that still start with `initialize`, 2025-11-25, 2025-06-18, 2025-03-26 and 2024-11-05, answered without a session. Claude Code's newer runtime asks for 2026-07-28 first, with `server/discover`. Cursor and VS Code start with `initialize`. Both ways are tested with the official MCP TypeScript client, and against the official conformance suite's scenarios that apply to a tools-only server.

Browsers on other sites get no CORS headers, so they cannot read the answers. Requests are answered whatever their `Origin`, because hosted clients send one from their servers. `allowedOrigins: ['https://app.example.com']` turns on MCP's origin check: requests from any other origin get a 403, and the listed ones get CORS headers.

## Show it on your site

Give the Docusaurus or Starlight plugin the endpoint's URL with `mcp`, and a page can show how to add it to Cursor, VS Code, Claude, Claude Code and ChatGPT:

- **Docusaurus:** `['ask-my-site/docusaurus', { mcp: '/api/mcp' }]`, then in an MDX page, `import AskMySiteMcp from '@theme/AskMySiteMcp'` and `<AskMySiteMcp />`.
- **Astro and Starlight:** `askMySite({ mcp: '/api/mcp' })`, with `site` set, then in an MDX page, `import McpInstall from 'ask-my-site/astro/McpInstall.astro'` and `<McpInstall />`.
- **React:** `<McpInstall url="https://docs.example.com/api/mcp" name="acme-docs" />` from `ask-my-site/react`.
- **Anything else:** `mcpInstallLinks({ url, name })` from `ask-my-site` returns the Cursor and VS Code install links, the claude.ai link, the Claude Code command and the JSON for other clients.

A path is resolved against the site's URL. The name defaults to the site title, as `acme-docs`.

## Try it locally

`npx ask-my-site dev` serves the index at `http://localhost:8787/api/mcp` as well as the ask endpoint, keyword-only, with the same origin and host checks:

```sh
npx ask-my-site dev
claude mcp add --transport http docs http://localhost:8787/api/mcp
```

## Handler options

| Option                     | Default            | Notes                                                                                                                             |
| -------------------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `index`                    | required           | As for `createAskHandler`. The same imported object as the ask endpoint's is loaded once.                                         |
| `embeddingModel`           | none               | Embeds each search query. Without it, search is keyword-only and no model is called.                                              |
| `embeddingProviderOptions` | none               | As for `createAskHandler`.                                                                                                        |
| `siteName`                 | `"this site"`      | Names the docs in the tools' descriptions, which the agent reads.                                                                 |
| `siteUrl`                  | the request's      | The origin to make URLs absolute with, when the endpoint runs on another host. `false` keeps the index's URLs.                    |
| `name`, `instructions`     | `ask-my-site`      | The server's name, and what it tells the agent about using the tools.                                                             |
| `retrieval`                | keyword gate `0.3` | Retrieval settings for `search`; it keeps sections with at least 30% of the query's keyword weight, looser than the ask endpoint. |
| `rateLimit`                | 60 a minute per IP | Any limiter, or `false`. `rateLimitFailure` works as for `createAskHandler`.                                                      |
| `budget`                   | none               | `{ requestsPerDay, store }`: tool calls a day.                                                                                    |
| `allowedOrigins`           | none               | A list of origins, or `'*'`, to check `Origin` and send CORS headers.                                                             |
| `maxQueryLength`           | `500`              | Longest search query, in characters.                                                                                              |
| `maxBodyBytes`             | 64 KiB             | Counted while reading.                                                                                                            |
| `onToolCall`               | none               | `{ tool, arguments, isError, results, retrieval, durationMs }` after each call, to count agent traffic.                           |
| `onError`                  | `console.error`    | Handled errors: embedding fallbacks, a failing limiter, a misconfigured index.                                                    |
